# Sign In & Sign Up Automation Testing using Cypress

This project demonstrates end-to-end automation testing for Sign In and Sign Up functionality using Cypress.  
It covers positive, negative, validation, UI behavior, and logout scenarios with reusable test data.

---

## 🎯 Project Objective

The main goal of this project is to:
- Validate login and signup functionality
- Handle positive and negative test scenarios
- Verify error messages and redirections
- Test logout behavior and session handling
- Practice Cypress automation with fixtures and validations

---

## ✅ Test Scenarios Covered

### 1. Signup Functionality
- Create fixture data for multiple users  
- Sign up with 5–10 different users  
- Validate credentials using test data  

### 2. Login Functionality
- Login using multiple valid users  

### 3. Signup with Invalid Data
- Mandatory field validation  
- Block submission for empty input  
- Prevent invalid data submission  
- Validate incorrect formats (text in phone, number in name)  

### 4. Login with Invalid Credential
- Verify login fails for wrong credentials  

### 5. Error Message Validation
- Correct error message displayed  
- Error message disappears after fixing input  

### 6. Logout Functionality
- User logs out successfully  
- Back button does not reopen application  
- User redirected to login page
